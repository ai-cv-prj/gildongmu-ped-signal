## 작은 신호등과 복수 신호등

| 분할 | 작은 신호등 검출 / GT | 작은 신호등 recall | 복수 신호등 이미지 | 해당 이미지의 신호등 recall |

| val | 1120 / 1170 | 95.73% | 29 | 82.54% (52/63) |
| test | 1126 / 1170 | 96.24% | 30 | 82.81% (53/64) |

작은 신호등은 디코딩된 전송 이미지의 GT 박스 면적 <1,024px²로 정의했다. test 복수 신호등 이미지에서는 64개 중 53개를 찾아 recall 82.81%이며, 그 안의 작은 신호등 recall은 43/54=79.63%다. 전체 평균보다 어려운 조건의 성능이 낮다.

## 결과 해석

- 새 test 3,680장 중 복수 신호등 이미지는 30장(약 0.82%)이다. 전체 평균만으로 복잡한 교차로 문제까지 해결됐다고 판단하지 않는다.
- 신호등 오검출 207개 중 172개는 신호등 GT 라벨이 없는 이미지에서 발생했다. 실제 오검출인지 라벨 누락인지는 시각 검토가 필요하며, 현재 지표에서는 FP로 계산했다.
- 새 test 중 이전 train에서 이동한 3,619장은 이번 모델의 학습에서는 제외했다. 원본 사전학습 가중치에서 새로 시작했으므로 이 사실 자체가 이번 모델의 학습/평가 중복을 의미하지 않는다.
- 이전 test 45장과 현재 test 3,680장은 구성이 다르다. 이전 55.53%와 현재 84.10%의 차이를 재분할에 의한 순수 성능 향상 폭으로 해석하지 않는다. 최대 epoch도 이전 30에서 50으로 달라졌다.
- 이전 test에서 새 test에 남은 5장에서는 신호등 recall이 13/14였지만, 극소수 표본이므로 기존 전체 test와 비교하지 않는다.
- 동일 원본 해시/파일번호 그룹은 분할 간 중복이 없었다. 그룹은 파일번호 기반 휴리스틱이므로 촬영 장소나 유사 장면의 완전 독립성까지 보장하지 않는다.
- 색상 분류, 신호등↔횡단보도 연결, 실제 앱 응답시간은 이번 평가 범위에 포함하지 않았다.

## 평가 조건과 시간

- Ultralytics 8.4.150, torch 2.11.0+cu128, RTX 5080 Laptop GPU, imgsz=960, batch=16, FP32, rect=True, augmentation 없음.
- 공식 AP: confidence=0.001, NMS IoU=0.7, max_det=300.
- 운영 지표: confidence=0.4, 클래스별 confidence 순 일대일 매칭, GT IoU≥0.5.
- JSON의 official Box-P/Box-R은 검증기의 F1 기준 임계값에 따른 값이다. 위 표는 고정 confidence=0.4 값이다.
- 순수 검출기 추론 시간: val 이미지당 2.66ms, test 이미지당 2.67ms. 배치 처리 평균이며 파일 읽기·디코딩·전후처리·색상 분류·네트워크를 제외한다.
